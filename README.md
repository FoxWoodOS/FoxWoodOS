## About

FoxWood OS is an independent operating system project developed from scratch by Ayaz.

It features its own kernel, command-line interface and graphical desktop environment. It is not based on Linux or any existing Linux distribution.

The project aims to explore low-level programming, operating system architecture and the fundamentals of computer systems.

## Features

- Custom x86_64 kernel
- Independent bootable system
- Command-line interface
- Custom graphical desktop environment
- Window management
- Built-in applications
- Custom system architecture
